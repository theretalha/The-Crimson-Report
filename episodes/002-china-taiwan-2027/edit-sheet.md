# EP 002 — Why China Wants Taiwan by 2027 — Edit Sheet

**Length:** ~10 min (≈1,500 words at ~150 wpm)
**Rule:** new visual every 3–5 seconds. One idea, one object per scene.
**Top bar on every scene:** `THE CRIMSON FORECAST · 0X / CHAPTER NAME · FORECAST FILE · 0NN`
**Bottom:** karaoke captions (keyword in crimson box) + source line (bottom left) + progress bar.

## Colour moods
| Mood | Background | Use when |
|---|---|---|
| Context | Black `#0E0E0E` | history, explaining |
| Danger | Crimson `#B3121B` | war, threat, blockade, losses |
| Facts | Off-white `#F2EEE6` | numbers, charts, quotes, the forecast |

## Scene templates (reuse these 8)
1. **TITLE CARD**: big headline + subline, one icon in centre
2. **MAP**: dark map, Taiwan/China highlighted crimson, animated arrows
3. **STAT**: one giant number counting up ("90%", "$10T")
4. **QUOTE**: silhouette of the speaker, quote card, source
5. **TIMELINE**: horizontal line with dates popping in
6. **SPLIT**: left vs right comparison
7. **CARDS**: 3 numbered cards (reasons, scenarios, signals)
8. **ICON MOMENT**: single animated icon (chip, ship, cable, door)
